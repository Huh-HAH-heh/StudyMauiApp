# Браузерная версия StudyMauiApp

Интерфейс перенесён из MAUI/XAML в HTML, CSS и JavaScript. Открывается в обычном браузере, не требует .NET, MAUI или Uno Platform. Исходный MAUI-проект сохранён без изменений.

## Локальный запуск

На Windows дважды запустите run-web.ps1 из корня репозитория. Скрипт поднимет локальный сервер и откроет страницу в браузере.

Либо из корня репозитория выполните:

    py -m http.server 8080 --directory web

Откройте http://localhost:8080.

| Ветеринар | vet | vet |

## Перенесённые сценарии

- Обзор приюта и статистика.
- Журнал животных, поиск и фильтры.
- Регистрация животного для администратора и волонтёра.
- Создание заявок на усыновление и передачу животного в приют для клиента.
- Просмотр заявок и оформление выдачи питомца для сотрудников.
- Ветеринарный журнал для ветеринара.
- Отчёт приюта для администратора.

Данные сохраняются в localStorage текущего браузера. Это демонстрационный режим: разные браузеры и устройства не синхронизируются. Пароли встроены только для учебной демонстрации; для реального использования нужна серверная API.

## Публикация через GitHub Pages

В репозитории откройте Settings → Pages и выберите публикацию из ветки feature/uno-webassembly, папка /web. После сохранения GitHub Pages покажет адрес сайта.
